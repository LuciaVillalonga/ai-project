How this website was made

I made the website by organizing it into 6 pages, answering each of the questions and including a source and visual designs to it. I prompted ChatGPT to use a color palette of blue, cream, green, red, orange, and I used black for the text. The different colors identified with the text regarding AI’s challenges and benefits and general information. I used semantic HTML for the structure of the website, CSS for the layout and a bit of JavaScript for the interactivity such as linking the sources below the text to take you to the source page, with the help of AI to create the codes. AI assisted me in creating the website after I put in all the inputs I wanted to include including structure, instructions, and content. When first testing it, AI would alter the content of the website and switch up the answers I had created, but this was resolved after making additional changes to the prompt given.

I acknowledge the use of ChatGPT to create the structure, review codes, and suggest revisions. I checked the facts, edited the content and tested the code. The final work is my responsibility.
